# 家庭生命周期地图

> 交互工具：选视角 → 标出「你在哪一段」→ 左右滑看节点 / 风险 / 保险作用  
> 可导出小红书长图 · 可作微信网页线索磁铁  
> 定位：家庭理财学习笔记 · 科普框架（非产品推介）

---

## 功能

1. **三种视角**：一个人 / 双人家庭 / 有娃家庭  
2. **你现在在哪一段**：填大概年龄（可选性别、可选「钱的松紧」；有娃可填孩子年龄）→ 自动标「你在这里」；阶段卡含**健康风险条**（癌 / 卒中 / 心血管等年龄带相对高低）+ 可核对终生锚点  
3. **准备点 / 兑现点**：每阶段标出「现在该为哪件以后的事占窗口」与「本阶段在兑现什么」，点「查看兑现阶段」可跳转  
4. **横向时间轴**：节点 · 风险 · 保险作用 · 一句话小结（「钱的松紧」只改保障优先级与小结语气，不改阶段定位）  
5. **保存本阶段图**：只导出「你在这里」或当前浏览的那一段，方便发小红书 / 存相册（每人内容不同）  
6. **线索磁铁**：底栏「加微信」+ 三问话术复制；链接可带 `?wx=微信号`

## 怎么用

### 家里总控（已部署）

http://100.117.220.14:8091/?wx=achealth&profile=family

改完后在本目录 `git push origin master` 会更新线上。

### 本地预览

```bash
cd ~/cursor/Insurance/lifecycle-map
python3 -m http.server 8765
```

微信里打开 **https 域名** 更稳（http 可能被拦截）。分享示例：

```text
http://100.117.220.14:8091/?wx=你的微信号&profile=family
```

险种适配配套表（同一套视角与「钱的松紧」）：

```text
http://100.117.220.14:8091/fit/?profile=family&money=tight
```

常用参数：

| 参数 | 含义 |
|------|------|
| `wx` | 展示 / 复制用的微信号 |
| `profile` | `single` / `couple` / `family` |
| `age` | 成人年龄 |
| `child` | 孩子年龄（有娃） |
| `sex` | `female` / `male` / `na`（健康提示用，可选） |
| `money` | `tight` / `ok` / `ample`（钱的松紧：手头紧一点 / 大致够用 / 相对宽裕；只调侧重点，可选） |
| `stage` | 跳到第 N 段（1 起） |

### 获客用法

1. **小红书**：工具内导出长图 → 配文「左右滑，看清你在哪一段」→ 评论区 / 私信发微信页链接  
2. **微信好友 / 朋友圈 / 公众号菜单**：直接发带 `?wx=` 的链接，对方加你后回三问  
3. **首咨**：一起打开，先问「你觉得自己在哪一段？」再展开缺口

### 改默认微信号

当前默认已是 **`achealth`**。若要改，打开 `index.html`：

```js
const LEAD_CONFIG = {
  defaultWx: "achealth",
  brand: "家庭理财学习笔记"
};
```

或不改代码，分享时用 `?wx=` 覆盖。
