第 3 步 · 主要险种结构对照

内地 × 港险：医疗 / 重疾 / 寿险 / 储蓄差在哪

不构成产品推荐

下面只比较同类险种的常见结构差异，不点名任何具体产品，也不比较哪家「更好」或演示收益高低。正式结论以保险公司最新保单条款为准；是否适合配置，需结合你家阶段与现金流单独判断。

同一需求是「住院与医疗账单」。先分清普通百万、中端特需、高端与港险自愿医保，避免把一年期产品当成长期保障。

对照项 长期百万医疗（内地） 中端/特需医疗（内地） 一年期高端医疗 香港自愿医保（VHIS）
医院与病房范围 二级及以上公立医院普通部（通常不含特需/国际/VIP） 公立普通部 + 公立特需 / 国际部 / 指定私立 全球或全球除美，常见标准单人间 香港私家医院（半私家房 / 私家房）及约定亚洲/全球网络
保证续保 主流旗舰多为20 年保证续保（期间费率可调） 多为一年期、不保证续保 一年期、不保证续保 条款写明保证续保至高龄 / 终身（整体按年龄与通胀调费）
免赔 / 自付 常见年免赔约 1 万 0 / 数千 / 1 万余可选 0 至数万可选 0 自付，或设数万港币自付额换低保费
院外特药 按合同清单与认可药房报销 部分含院外药械限额或特需部内直付 通常覆盖合理必需的院外靶向与前沿疗法 按全数赔偿或分项限额覆盖订明非手术癌症治疗
更适合谁 长期常住内地家庭的底层医疗兜底 需要公立特需 / 少排队体验的家庭 跨国生活、私立医院直付需求 有赴港/在港就医能力者；常住内地、主要在内地看病者不宜作第一层

同一需求是「大病后的收入替代与康复期开销」。内地常见消费型重疾；香港危疾常带现金价值与分红，结构更复杂，不能按「保费贵便宜」直接对标。

对照项 内地消费型重疾（常见） 内地储蓄型重疾（较少作主力） 香港危疾（常见结构）
疾病定义口径 以监管核心重疾定义为基础，叠加轻症 / 中症 同左，但保单含现价，保费显著更高 以行业危疾定义为基础，常见早期危疾 + 严重危疾分组
等待期 常见 90 日或 180 日（意外多除外） 同类 严重危疾常见约 60 日（以条款为准）
赔付形态 确诊达到标准后一笔过给付；可含多次赔、额外癌症赔 保障 + 长期现金价值并存，杠杆通常低于消费型 严重危疾可分组多次（如癌/心/中风一组多次）；首次大赔后现价常归零
现金价值 / 分红 多数无现价或极低，主打高杠杆保额 有保证现金价值，部分含分红 常见有保证现价 + 非保证特别红利；主业仍是保障，不是增额寿
与身故责任关系 消费型常另设身故/退保返还已交保费或约定比例 现价与身故、重疾给付需按条款取高或冲减 多为加速给付：首次严重危疾后身故责任常终止或大幅变化
更适合谁 要先把3–5 年收入保额做够的内地家庭主力选择 预算极宽、想保障与储蓄绑一张单时再评估 已有内地保额底盘，且接受赴港投保、外币保单与更复杂条款的家庭作补充

同一需求是「经济支柱身故或全残后，房贷与抚养不断供」。纯杠杆优先看定期寿险；终身寿 / 储蓄寿是另一类目标，不要和定寿比「谁划算」。

对照项 内地定期寿险 香港定期寿险 终身 / 储蓄型人寿（两地均有）
核心功能 高杠杆覆盖剩余负债 + 抚养年限 同样是杠杆型身故保障，条款结构与核保规则按香港标准 身故保障 + 长期现金价值 / 传承安排，保费远高于定寿
保费与杠杆 同等保额下通常保费更低、杠杆更高，适合作为有房贷家庭的第一层 保费因年龄、币种、核保与市场定价而异，不宜默认「一定更贵/更便宜」 杠杆显著低于定寿；主要不解决「便宜覆盖房贷」
保险期间 常见保至 60 / 70 / 88 岁或固定年期；责任结束即停止 可保固定年期或至约定年龄；部分可转换 终身；或与储蓄计划长期绑定
币种与缴费 人民币计价，适配内地收入与房贷币种 常见港币 / 美元等；需匹配未来负债币种与换汇安排 内地多为人民币；香港常见美元及多币种切换
更适合谁 背负房贷、抚养或赡养责任的经济支柱（内地常住家庭通常先做这一层） 负债或生活重心在香港、或以港币/美元负债为主的家庭 保障已齐、有明确传承或长期锁仓目标时再谈；不能替代定寿的杠杆功能

同一需求是「把 10–30 年后要用的教育金 / 养老金锁住」。先分清保证利益与非保证演示；任何储蓄形态都不能排在大人医疗、重疾、定寿前面。

对照项 内地增额寿 / 年金（偏保证叙事） 内地分红储蓄 香港分红储蓄 / 年金（常见）
利益结构 强调保证现金价值按约定增长或保证领取 保证部分 + 非保证分红；演示与实际可能偏离 保证现金价值通常起步较低；长期演示大量来自非保证红利 / 终期分红
怎么读计划书 先核对保证现价表与回本年限，再看其他 把保证利益与分红利益分开看，不把演示合计当成承诺 先看保证现价与退保损失期；再查公司公布的红利实现率，不把高演示年化当预期收益
流动性 早期退保损失常见；减保 / 贷款规则因产品而异 同类，需看现金价值与分红结算时点 部分计划支持减保、部分提取、保费假期等，但仍有漫长低现价期
币种与用途 人民币，对接国内教育 / 养老开支较直接 人民币 常见美元及多币种；适合有外币支出、资产配置需求且能接受汇率波动者
前置条件 应急金 3–6 个月 + 大人医疗 / 重疾 / 定寿闭环之后，再用10 年以上确定不动用的闲钱启动。保费占比过高或用储蓄险顶替保障，属于顺序错误。
更适合谁 要确定现金流、厌恶演示波动的家庭 能理解分红波动、仍以保证利益托底的家庭 保障已齐、有赴港与外币安排能力，并把非保证部分当作「可能有、不是承诺」的家庭

声明：以上为同类险种的结构科普对照，不构成任何保险产品推荐、收益承诺或投保要约；不比较具体产品名称与报价。涉及香港保单的讨论与投保，须在符合监管要求下于香港境内合规进行。
