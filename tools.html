第 3 步 · 内地与香港方案怎么选

四大核心险种：内地 × 港险结构与分工对照

按目标分账 · 先看结构差异

很多家庭会问：「我们长住内地，该买内地保险还是香港保险？」答案不是谁淘汰谁，也不是谁只能做替补，而是按这笔钱要解决的目标分账——本地高频报销与纯人民币杠杆看内地，全球重症通道、保额抗通胀与跨周期多元货币锁仓看香港：

医疗险的核心是「平时在哪看病」与「重症时想进哪里的医院、用什么药」。普通住院靠内地本地医疗；若想锁定终身续保、亚洲/全球私立与香港同步新药通道，港险医疗具有结构优势。

对照项 内地长期百万医疗 内地中端 / 特需医疗 香港高端医疗 / VHIS 灵活计划
医院与病房范围 内地二级及以上公立医院普通部（不含特需/国际/VIP） 内地公立普通部 + 公立特需部 / 国际部 / 指定私立 香港私家医院 + 内地指定三甲（含特需/国际部）+ 亚洲/全球网络（半私家房或标准私家单人间）
续保确定性 主流旗舰为 20 年保证续保（期间费率可调） 多为一年期、不保证续保（理赔或停售可能影响续保） 条款写明保证终身续保或至 100 岁（不分摊个人理赔，按年龄与医疗通胀整体调费）
前沿新药与限额 每年数百万人民币；院外特药按合同清单报销 每年数百万人民币；特需部内用药更宽 年度限额常见 1,000 万–2,000 万港元以上（不设终身限额或极高），覆盖香港已上市国际前沿靶向/免疫疗法
免赔 / 自付额设计 常见年免赔 1 万人民币 常见 0 免赔或 5,000–1.5 万可选 可选 0 自付，或选 1.6 万 / 2.5 万 / 5 万港元自付额（用内地医保/百万医疗抵掉自付额，大幅降低港险保费）
各自适合做谁的主力 内地日常住院底盘：解决本地公立医院大额住院账单 内地就医体验升级：看重本地三甲特需专家号与少排队 重症跨境通道与终身锁仓主力：看重终身保证续保、赴港用国际新药/私家医院，或用「高自付额」衔接内地医保的中产家庭

重疾险不是「港险只能做补充」，而是两种完全不同的财务工具：内地消费型重疾是「纯保障杠杆」；香港分红危疾则是「自带抗通胀保额递增 + 癌症/心脑持续多次赔 + 有事赔钱、没事存钱」的复合主力方案。

对照项 内地消费型重疾（纯杠杆路线） 香港分红型危疾（保额递增 + 储蓄复合路线）
保额会不会随时间长大 固定保额（买 50 万，30 年后理赔仍是 50 万人民币，需自己另补通胀缺口） 保额随非保证特别红利逐年递增（持有时间越长，重疾与身故赔付额越高，天然对冲 20–30 年后的医疗与生活通胀）
现金价值与退路 偏纯消费或后期现价增长慢，主要买「出事赔一笔」 兼具保证现金价值 + 分红：一辈子平平安安到老，可退保拿回本金加长期红利转化为养老金，保费不白交
高发重疾多次赔付机制 常见单次赔，或附加二次癌/多次赔（间隔期与触发条件按内地规范） 主流旗舰支持癌症、心脏病、中风等高发组别多次持续赔付（累计可达原保额 500%–700%+），部分含确诊后按月现金支援
等待期与疾病定义 等待期常见 90–180 日；按内地监管统一 28 种核心重疾规范定义 等待期常见 60–90 日；按香港保险业联会（HKFI）标准定义，早期危疾与儿童特定疾病覆盖细腻
币种与核保尺度 人民币计价；体检异常按内地保司核保手册执行 美元 / 港币计价（分散单一币种风险）；部分常见体况（如部分结节、轻度指标异常）两地核保尺度存在差异，可双市场择优
各自适合做谁的主力 预算有限、追求极致首年杠杆：希望花最少的钱先把眼前 3–5 年人民币收入保额占满 中产及高净值家庭的重疾主力仓：不希望「没病保费打水漂」，看重美元资产配置、保额随年龄自动抗通胀及癌症持续多次保障

在 10–30 年跨度的教育金与养老金规划上，香港多元货币分红储蓄本身就是众多内地家庭的核心主力工具——它解决的是「长期利率下行环境中，如何跨币种、跨代际锁定复利」。

对照项 内地增额终寿 / 年金（人民币固收底盘） 内地分红型储蓄（人民币保证 + 浮动） 香港多元货币分红储蓄（全球配置主力）
底层资产与长期收益结构 全保证利益写入合同，预定利率受国内利率环境约束，确定性强但上限锁定 保证底线 + 人民币账户分红浮动 全球股债多元投资组合；保证现价托底 + 长期非保证复利空间显著更高（监管要求每年公开披露过往红利实现率）
货币选择与自由转换 仅人民币 仅人民币 支持美元、港币、人民币、英镑、加元、澳元等 6–9 种货币自由转换，无缝匹配孩子未来去哪个国家留学或家庭移居
保单拆分与家庭传承功能 功能相对固定，通常一张保单对应单一被保险人 同左 支持无限次更换受保人、设置后备受保人、保单拆分成多份（例如一张单拆给两个孩子，或三代接力传承不停复利）
提取灵活性 支持按规则减保或按约定年龄领年金 支持减保或红利提取 可按阶段灵活部分提取（如 18–22 岁每年提留学费、60 岁起提养老金），剩余资金继续在池中滚存
各自适合做谁的主力 纯国内开支、极度厌恶任何波动的保守型人民币底仓 希望留在人民币体系内、兼顾保底与一点浮动收益的家庭 内地家庭做教育金、养老金与跨代传承的主力选择：只要这笔钱 10 年以上不用，且希望配置美元/多币种资产、对冲单一利率下行

对照项 内地定期寿险（房贷期高杠杆） 香港定期寿险 / 终身人寿（大额保障与传承）
核心解决什么问题 用每年一两千元人民币，覆盖 30–60 岁工作期的房贷与未成年子女抚养责任 提供更高免体检/高保额上限、美元计价的身故保障，或通过分红人寿实现高杠杆资产传承与婚姻/债务隔离规划
定价与费率特点 内地互联网定寿竞争充分，常规保额（100–300 万人民币）费率极低、健告简洁 香港人均寿命全球领先，在大额保单、非吸烟体况及终身人寿杠杆上具备独特费率与分红累积优势
除外责任与条款细节 法定免责一般 3–7 条，2 年不可抗辩 条款极简（部分定期/终身寿险仅设首年或两年自杀免责，其余极端情况限制极少），理赔确定性高
各自适合做谁的主力 普通工薪与中产家庭的房贷护城河：先把人民币负债风险快速堵上 高收入支柱、企业主及有海外/多子女传承需求的家庭主力：需要大额美元身故杠杆、更少免责条款或长期财富定向交接
